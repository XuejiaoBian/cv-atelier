Make it yours.

Choose Text to write and select a passage. The toolbar reads the actual selection and shows Mixed when styles differ. Apply to lets you format body text, the selected section, or the whole document. Body text preserves headings. Bullets toggles a bulleted list for the current paragraph or selected paragraphs. The highlighted button means bullets are on.

Click a section on the page or in the left list, then choose Single column or Two columns under Selected section. Only that section changes; its heading spans both columns.

Choose Position sections, click a section, and drag it on the page. It snaps to a 1 mm grid and nearby edges. Arrow keys nudge 0.25 mm; Shift nudges 1 mm. The left sidebar arrows reorder sections. Ctrl / ⌘ Z undoes; Ctrl / ⌘ Shift Z redoes.

HTML imports retain embedded styles. Scripts and frames are removed. Bundled fonts are embedded in saved HTML. External images and imported fonts must remain accessible. Relative assets should be embedded in the HTML first. Use Link or Ctrl / ⌘ K to add, edit, or remove a hyperlink.
